# 星临 Logo

定版：**G2 明珠 · 玻璃 · 靛金 · 细节 A 精修**（2026-09-26）。设计过程见 `design/preview/logo.html`（第四轮）和 `logo-v1 ~ v3.html`。

星从天而降，落进王冠正中的缺口，成为冠上的明珠——"驾临"。

## 文件

| 文件 | 用途 |
|---|---|
| `logo.svg` | 标准版，40 像素以上使用（后台登录页、宣传图、应用图标） |
| `logo-small.svg` | 小尺寸版，32 像素及以下使用（浏览器标签、侧栏）：去掉光迹细节、线条加粗、星更大 |
| `logo-animated.svg` | 降临动画（循环），登录页用只播一次的版本（见 `apps/admin/src/components/Logo.vue`） |
| `png/logo-*.png` | 16 ~ 1024 像素（16 / 32 / 48 另有 `logo-small-*.png`） |
| `favicon.ico` | 16 / 32 / 48（小尺寸版）+ 64 / 256（标准版） |
| `*.tpl.svg` | 模板：`__ID__` 会替换成每个实例独立的编号，避免同一页面多个 logo 的渐变互相影响 |

## 颜色

| 用途 | 颜色 |
|---|---|
| 底板 | `#3A37A0` → `#17164A` → `#0A0A1C`（星辉靛） |
| 光晕 | `#8D8BFF` |
| 王冠 / 星 | `#FFF3D6` → `#F2C46E` → `#B8741F`（金） |

特别版「玄金」（底板 `#34343F` → `#050507`、香槟金 `#E3C58E`）见设计稿，暂不使用。
