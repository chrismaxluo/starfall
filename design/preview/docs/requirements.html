1. 项目概述

星临（Starfall） 是一个给主播自己的 B 站直播间使用的直播互动特效工具。观众进场、发弹幕、送礼物、上舰时，按主播设定的规则，在直播画面上播放对应的动画、欢迎语和音效。

  • 使用者：主播本人，只服务一个直播间。
  • 参考产品：花花直播助手的进场特效（同类还有 MoeMaster 直播助手）。
  • 与参考产品的差异：花花是装在主播电脑上的 Windows 软件；星临开发期先做成网页服务，通过浏览器源接入直播软件，后续再封装成 Windows 客户端。两者共用一套代码。
  • 产品形态： 1. 开发阶段：部署在服务器上的网页版（管理后台 + 特效页）。 2. 后续：用 Electron 封装成 Windows 客户端，在其他电脑上打包。封装后界面与网页版一致，直播软件里的地址改为 127.0.0.1。

2. 范围

2.1 第一期（本次开发）

模块 内容
B站连接 小号扫码登录、连接直播间、断线重连、识别开播 / 下播
触发规则 进场、弹幕（关键词）、礼物、上舰 四种事件
素材库 动画素材（上传即可用）、内置素材、音效
播放 统一播放队列、优先级、插队、紧急暂停
输出 特效页（浏览器源），默认竖屏，适配 B站直播姬 和 OBS
管理后台 总览、触发规则、素材库、事件记录、直播软件输出、设置、新手引导
数据 所有事件入库（为第二期统计做准备）、配置导出导入、自动备份

2.2 第一期不做

  • 醒目留言（SC）、关注、点赞触发
  • 数据统计（礼物收入、直播数据报表）、观众档案
  • 念欢迎语音（TTS）、弹幕点歌、排队、自动发弹幕
  • 多直播间 / 多主播

2.3 第二期规划（仅记录方向，不在本次范围）

  • SC、关注、点赞触发
  • 礼物统计、直播数据、观众档案（首次进场 / 老粉回归 / 来访里程碑）
  • 画面组件：礼物目标进度条、本场贡献榜、弹幕姬
  • 欢迎语音

3. 使用环境

项目 内容
直播方式 以竖屏为主，用电脑直播
直播软件 B站直播姬 和 OBS Studio 都要支持
默认画布 竖屏 1080 × 1920，可切换横屏和其他分辨率
开发 / 部署服务器 Azure 东京机房，Debian 12，2 核，857 MB 内存 + 2 GB swap
项目目录 /opt/starfall
管理后台访问 浏览器，电脑和手机都能用

4. 核心概念

名称 含义
事件 直播间里发生的事：进场、弹幕、礼物、上舰
触发规则 "谁、做了什么 → 播放哪个素材"。按事件分开设置
素材 可以直接播放的特效。上传一个动画文件就得到一个素材；另有内置素材
音效 单独管理的声音文件，可以被多个素材共用
身份档位 进场规则的固定分档：总督、提督、舰长、房管、粉丝牌分档、普通观众
专属用户 按 UID 指定某个人的专属素材，只对进场生效
分档 粉丝牌等级、礼物价值按区间分档，区间自动切分，不会重叠
冷却 一段时间内不重复播放，防止刷屏
播放队列 所有事件的特效排在同一个队列里，依次播放
输出 一个特效页地址 + 一套画布设置，放进直播软件的浏览器源
安全区 竖屏时被 B站 App 界面遮挡的区域（顶部信息栏、底部弹幕礼物区），特效自动避开

5. 功能需求

编号规则：F-模块-序号。待验证 表示依赖 B 站协议实测，技术验证阶段确认。

5.1 B站连接

编号 需求
F-BL-01 用 B 站 App 扫码登录小号，保存登录信息（Cookie）。不直接要求用户粘贴 Cookie
F-BL-02 显示登录状态、UID、预计有效天数；快过期或失效时提醒重新扫码
F-BL-03 填写房间号后连接直播间，显示主播昵称和房间信息
F-BL-04 通过非官方 WebSocket 接收直播间消息：认证、30 秒心跳、解压（brotli / zlib）、解析 JSON 与 protobuf 两种格式
F-BL-05 断线自动重连，后台显示连接状态和延迟
F-BL-06 识别观众身份：大航海等级（总督 / 提督 / 舰长）、房管、本直播间粉丝牌及等级、神秘人待验证：房管、神秘人
F-BL-07 识别开播 / 下播状态，顶栏显示直播时长
F-BL-08 需要处理的消息：进场（INTERACT_WORD 及新版格式）、大航海进场（ENTRY_EFFECT）、弹幕（DANMU_MSG）、礼物（SEND_GIFT / 连击）、上舰（GUARD_BUY 等）、开播 / 下播待验证：具体字段与新版格式
F-BL-09 大航海官方图标、粉丝牌颜色运行时从 B 站读取，不打包进软件

5.2 触发规则

5.2.1 通用

编号 需求
F-RU-01 规则页按事件分为 进场 / 弹幕 / 礼物 / 上舰 四个标签
F-RU-02 每条规则选择一个素材播放；素材选择器分"我的素材 / 内置素材"，可在选择器里直接上传新素材并自动选中
F-RU-03 每条规则可单独启用 / 停用
F-RU-04 规则行的 ▶ 只在页面内本地预览；"发送到直播测试"是独立按钮，需要点两次确认
F-RU-05 模拟一次事件：输入观众、弹幕内容、礼物和数量、上舰等级和月数，显示"命中哪条规则、播放哪个素材"，并提示黑名单 / 暂停 / 未开播等不播放的原因
F-RU-06 事件判断顺序：黑名单 → 匹配规则 → 是否暂停 → 是否开播 → 冷却，任一不通过则不播放，但照常记录

5.2.2 进场

编号 需求
F-EN-01 固定匹配顺序：专属用户 → 总督 → 提督 → 舰长 → 房管 → 粉丝牌（高等级档优先）→ 普通观众。命中第一条即停止
F-EN-02 身份档位是固定行，不能重复添加、不能修改类型；每行直接选素材、设冷却、开关
F-EN-03 大航海和粉丝牌只计算本直播间
F-EN-04 粉丝牌分档：输入"从 N 级起"添加，自动切分区间，不会重叠；删除某档后并入相邻档；至少保留一档
F-EN-05 普通观众规则默认关闭
F-EN-06 专属用户：按人管理（头像、昵称、UID、身份、素材、冷却、有效期、开关）。添加方式：输入 UID 查询、从事件记录选、从大航海名单选。同一 UID 只能有一条，重复添加时直接定位到已有记录
F-EN-07 专属用户可设有效期（例如生日当天），到期自动失效，改回按身份档位播放
F-EN-08 专属只对进场生效，礼物、弹幕、上舰按各自规则播放
F-EN-09 冷却方式二选一：按分钟（每条规则单独设置），或每场直播每人只播一次（开播时重新计算）
F-EN-10 舰长进场会同时收到 INTERACT_WORD 和 ENTRY_EFFECT，需要合并去重，只播一次

5.2.3 弹幕

编号 需求
F-DM-01 规则包含：一个或多个关键词、匹配方式（包含 / 完全一致）、发送人条件（所有人 / 戴本房间粉丝牌 / 粉丝牌 ≥ 10 级 / 大航海 / 房管）、素材
F-DM-02 冷却分两种：全局冷却（秒） 和 每人冷却（分钟）
F-DM-03 从上到下匹配，命中即停；可用上下箭头调整顺序
F-DM-04 同一关键词出现在多条规则里时提示"排在前面的优先"

5.2.4 礼物

编号 需求
F-GF-01 指定礼物优先：某种礼物对应某个素材，每种礼物只能设一条
F-GF-02 按单次价值分档：价值 = 数量 × 单价（元）。分档自动切分、不重叠；低于最低档不播放
F-GF-03 免费礼物不触发
F-GF-04 连击合并：同一人在 N 秒内（默认 3 秒）连续送同一种礼物，合并为一次，用 {count} 显示数量
F-GF-05 礼物名称、单价从 B 站礼物配置接口读取待验证

5.2.5 上舰

编号 需求
F-GD-01 总督 / 提督 / 舰长各一行，开通和续费分别选素材
F-GD-02 欢迎语可用 {months} 显示月数

5.3 素材库

编号 需求
F-AS-01 页面分 动画素材（我的素材 + 内置素材）和 音效 两个标签；支持搜索、排序（最近 / 名称 / 使用次数）
F-AS-02 上传即素材：拖入或选择文件后直接成为可用素材，名称取文件名，自动读取尺寸和时长，默认居中播放
F-AS-03 支持格式：动画 透明 WebM（推荐）、MP4、SVGA、Lottie（.json）、GIF、PNG、APNG、WebP；音效 MP3、WAV、OGG
F-AS-04 上传提醒：没有透明通道（会挡住画面）、超过 10 MB（加载慢）
F-AS-05 素材卡片为竖屏缩略图，鼠标悬停时播放，显示格式、尺寸、时长、大小、"用于哪些规则"
F-AS-06 素材设置（编辑器），左侧大尺寸竖屏预览，右侧分四组：①画面 ②头像和欢迎语 ③音效 ④位置与时长
F-AS-07 画面：显示当前文件，可替换文件，替换后所有用到它的规则自动生效
F-AS-08 头像和欢迎语：上传的素材默认不叠加（素材可能自带文字），可打开；内置素材自带
F-AS-09 欢迎语按事件分开写（通用 / 礼物时 / 上舰时 / 弹幕时），没写的事件使用通用；每行一句，随机选一句
F-AS-10 欢迎语变量：{name} 昵称、{guard} 大航海、{medal} 牌子、{level} 等级、{text} 弹幕内容、{gift} 礼物、{count} 数量、{value} 价值、{months} 上舰月数
F-AS-11 音效：从音效列表选择，或在下拉中当场上传；可试听、调音量
F-AS-12 位置：左下 / 右下 / 顶部 / 居中；时长可调；竖屏时自动避开安全区
F-AS-13 内置素材：星冕、流星、流光、巡场、霜玻、礼物感谢、弹幕回应、一行字。只读，点"复制并编辑"得到副本，并可勾选"把原来用它的地方换成副本"
F-AS-14 删除保护：正在被规则使用的素材、正在被素材使用的音效不能删除，并提示在哪里使用；删除没人用的素材时，文件一并删除
F-AS-15 素材名称不能重复

5.4 播放与队列

编号 需求
F-PL-01 所有事件共用一个播放队列，依次播放，不叠加
F-PL-02 优先级：上舰 > 礼物 > 进场 > 弹幕
F-PL-03 高价值插队（可关闭）：上舰和 ≥ 100 元礼物立即播放
F-PL-04 最多排队数可设（默认 10）；排满后先丢弃优先级最低、最早进入的特效
F-PL-05 紧急暂停：顶栏一键暂停所有特效（快捷键 Ctrl + Shift + P），暂停后显示醒目提示条；事件照常记录
F-PL-06 清空队列：一键清空待播放的特效
F-PL-07 未开播时默认不播放；可改为"照常播放（排练用）"
F-PL-08 黑名单：黑名单里的人不触发任何特效。默认包含小号和主播本人；可在设置、事件记录、实时动态中拉黑

5.5 输出（特效页）

编号 需求
F-OU-01 特效页是一个透明背景网页，作为浏览器源放进直播软件的最上层
F-OU-02 画布方向：竖屏（默认） / 横屏；分辨率预设（竖屏 1080×1920 推荐、720×1280、1440×2560；横屏同理）或自定义；方向与宽高不一致、分辨率过高时提示
F-OU-03 竖屏安全区：顶部信息栏（默认 12%）、底部弹幕礼物区（默认 32%），可调，特效自动避开待校准
F-OU-04 全局外观：整体缩放、左右边距
F-OU-05 支持多个输出（例如竖屏直播 + 横屏录播），各自独立设置和地址
F-OU-06 地址带访问密钥，默认隐藏，可复制、可重置（重置需确认，旧地址失效）
F-OU-07 选择直播软件（B站直播姬 / OBS），显示对应的添加步骤，宽高自动填好
F-OU-08 兼容模式（自动 / 始终开启 / 关闭）：关闭毛玻璃、粒子等较重的效果；不支持的效果自动降级，不影响播放
F-OU-09 兼容性自检页：显示运行环境、内核版本、透明视频、毛玻璃、动态描边、声音、WebSocket 是否可用
F-OU-10 声音测试页：循环播放测试音和特效，显示音频是否被拦截
F-OU-11 特效页上报运行环境，后台显示已连接的特效页（软件、内核、分辨率、延迟、降级情况）
F-OU-12 特效页断线自动重连；直播软件没打开时特效不积压，恢复后只处理新事件

5.6 管理后台

编号 需求
F-UI-01 页面：总览、触发规则、素材库、事件记录、直播软件输出、设置；数据统计显示为"第二期"
F-UI-02 总览：今日进场（去重）、触发特效次数、在线人数（带迷你趋势图）、连接状态、实时动态（进场 / 弹幕 / 礼物 / 上舰）、特效预览与测试、身份构成
F-UI-03 实时动态、事件记录中点击观众：设置专属素材（小窗口完成，不跳页）、复制 UID、加入黑名单
F-UI-04 事件记录：记录所有事件的时间、观众、事件内容、命中规则、播放状态（已播放 / 未命中规则 / 已暂停 / 未开播 / 本场已播过 / 黑名单）；按事件类型、播放状态筛选，搜索昵称或 UID
F-UI-05 设置：B站账号、直播间、播放方式（未开播时）、黑名单、后台密码、数据备份与导入导出、保留期
F-UI-06 新手引导（首次使用自动弹出，可跳过，可在设置中重新打开）：扫码登录 → 填房间号 → 加到直播软件 → 发送测试特效
F-UI-07 命令面板（Ctrl + K）：搜索并执行常用操作（预览、暂停、清空队列、跳转页面等）
F-UI-08 亮色 / 暗色：默认跟随系统，可手动切换，切换时有从按钮位置扩散的过渡动画
F-UI-09 手机可用：窄屏时显示底部导航（总览 / 规则 / 素材 / 记录 / 更多）
F-UI-10 管理后台需要密码登录，首次部署生成初始密码

5.7 数据

编号 需求
F-DA-01 所有事件入库（即使第一期不做统计），字段包括时间、事件类型、观众、身份、原始数据、命中规则、播放状态
F-DA-02 事件记录保留期可设（30 / 90 / 180 天 / 永久，默认 90 天）
F-DA-03 每天自动备份配置和素材清单
F-DA-04 导出 / 导入配置（规则、素材清单、设置），导入前预览变化；导出文件可导入以后的 Windows 版

6. 界面与视觉

项目 规范
风格 高级感、有层次、现代化，参考 Linear、Vercel、Raycast 等产品：克制、精致、有深度
品牌色 单一主色 星辉靛：亮色 #5451D6，暗色 #8D8BFF。只用于主按钮、选中状态和关键数据
层级 背景 → 侧栏 → 卡片 → 浮层四层。暗色靠亮度区分，亮色靠柔和阴影和 1px 细描边区分；毛玻璃只用于浮层
字体 预览使用思源黑体 + Geist（数字用等宽字体，跳动时不抖）；正式版可评估 MiSans / HarmonyOS Sans
身份色 总督金、提督紫、舰长蓝、房管青、普通灰，只用于标签和数据
粉丝牌配色 按 B 站新版等级区间（接口实测）：1–10 #5762A7、11–20 #C770A4、21–30 #3FB4F6、31–40 #4C7DFF、41–50 #A773F1、56+ #EC4F6E；大航海成员有亮色描边。正式版直接使用 B 站下发的颜色值
大航海图标 使用 B 站官方图标，运行时加载（预览中为临时图标）待获取
品牌元素 星空元素只出现在 Logo、空状态、引导等少数地方

7. 非功能需求

编号 类别 要求
N-01 实时性 收到 B 站消息到特效页开始播放，目标 < 300 ms（不含直播推流本身的延迟）
N-02 稳定性 断线自动重连；服务崩溃自动重启；开机自启
N-03 兼容性 OBS 浏览器源（已实测通过）；B站直播姬浏览器素材（待实测）；管理后台支持主流桌面和手机浏览器
N-04 安全 管理后台密码登录；特效页地址带密钥；B 站登录信息只保存在本机或本服务器；有域名后启用 HTTPS

N-06 可移植 代码不依赖 Linux 专有能力，便于封装 Windows 版；配置可导出导入

11. 验收场景

  1. 舰长进场：舰长进入直播间，特效页在 1 秒内开始播放舰长素材；同一次进场只播一次（F-EN-10）。
  2. 专属用户：给某个 UID 设专属素材后 TA 进场，播放专属素材而不是身份档位素材；设了有效期的，过期后恢复身份档位。
  3. 每场一次：开启"每场只播一次"后，同一人本场再次进场不播放，事件记录显示"本场已播过"；重新开播后恢复。
  4. 弹幕：粉丝发"生日快乐"，播放对应素材；全局冷却内其他人再发不重复播放。
  5. 礼物：送出指定礼物，播放指定素材；送出 ≥ 100 元的礼物播放高档素材，并按设置插队；连续连击合并为一次，显示数量。
  6. 上舰：有人开通或续费，播放对应素材，欢迎语显示月数。
  7. 紧急暂停：按 Ctrl + Shift + P 后所有特效立即停止，事件照常记录；恢复后正常播放。
  8. 黑名单 / 未开播：黑名单用户、未开播时的事件都不播放，事件记录里写明原因。
  9. 素材：上传透明 WebM 后，不需要其他设置，就能在规则里选用并正确播放；替换文件后规则自动使用新文件；在用的素材删不掉。
  10. 竖屏：1080×1920 竖屏下，特效不进入安全区；在 OBS 和直播姬里显示一致。
  11. 断线：断网后恢复，自动重连，后台有提示。
  12. 手机：用手机打开管理后台，可以暂停特效、设置专属用户。
