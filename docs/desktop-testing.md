# 桌面版测试清单

> 功能是否正常看[功能验收清单](acceptance.md)，服务器版和桌面版共用。本清单只查**电脑环境**带来的问题：Windows 安全提示、中文路径、杀毒软件、端口、睡眠唤醒、资源占用等。服务器版没有这些问题，所以单独列出。
>
> 每个桌面版测试版和正式版发布前做一遍。标了 ★ 的项是**发版必测**，其余在大版本或改动了相关部分时做。

## 0. 测试电脑

至少准备两台（或虚拟机），尽量覆盖下面的情况：

| 项目 | 电脑 1 | 电脑 2 |
|---|---|---|
| 系统 | Windows 11 64 位 | Windows 10 64 位（22H2） |
| Windows 用户名 | **中文**（例如「主播」） | 英文 |
| 账户类型 | 普通用户（不是管理员） | 管理员 |
| 杀毒软件 | 只有 Windows 安全中心 | 火绒或 360（国内主播常用） |
| 显示缩放 | 150% | 100% |
| 直播软件 | B 站直播姬 | OBS Studio |
| 网络 | 家庭宽带 | 开着代理软件（例如 Clash） |

## 11. 已知风险

测试中遇到时，按这里的说明判断是不是问题。

| 风险 | 现在的情况 | 以后的处理 |
|---|---|---|
| 没有数字签名 | 安装时一定会出「Windows 已保护你的电脑」，部分杀毒软件可能误报 | 暂不购买签名证书；在下载页和使用说明里写清楚怎么继续安装 |
| 国内访问 GitHub | 下载安装包和自动更新可能很慢或失败 | 测试时记下实际速度；需要时再加国内下载地址 |
| 睡眠唤醒后重连 | 星临每 5 秒看一次时间，发现时间跳了一大段就马上重连；唤醒时网络还没连上的话，按正常的断线重连等几秒再试 | 如果 R-01 实测仍然慢，看日志里有没有「电脑睡眠或程序暂停了」 |
| B 站账号安全检查 | 桌面版用主播家里的网络连接，比服务器更不容易触发；同一账号同时在服务器版和桌面版登录可能触发 | 建议用小号，不要两边同时登录同一个账号 |
