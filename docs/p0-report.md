## 2. 与原方案不一样的地方

这些是只有实测才能发现的问题，都已经写进方案设计和需求文档：

| 发现 | 影响 | 处理 |
|---|---|---|
| 进场、送礼都换成了 protobuf 新版消息，旧版不再出现 | 按旧资料写的解析代码会完全收不到进场和礼物 | 以新版消息为准，字段见协议笔记 |
| 同名礼物有多个 ID、价格不同（如小电视飞船 1245 元 / 2999 元） | 按名字匹配会配错礼物 | 指定礼物**按 ID 匹配**，从本直播间礼物面板选择 |
| 名为 `UNIVERSAL_EVENT_GIFT` 的消息其实是连麦状态 | 容易被误当成礼物 | 忽略 |
| `ENTRY_EFFECT` 不只大航海才有，财富等级也会触发 | 去重逻辑不能假设它只来自大航海 | 按 UID 合并去重 |
| 细长屏手机会裁掉 9:16 画面左右各约 9% | 靠边的特效在观众手机上会被裁掉 | 新增左右边距，默认 9% |
| 熄灭的粉丝牌是灰色 | 自己按等级算颜色会不准 | 直接使用 B 站下发的颜色 |
| 直播间里有自动发"欢迎……"弹幕的账号 | 弹幕规则可能被它反复触发 | 用黑名单排除 |
| 超大直播间即使登录，昵称仍打码 | 不影响星临（只连主播自己的直播间） | 记录备查 |
