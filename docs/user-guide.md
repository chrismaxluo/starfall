# 使用手册

本文介绍星临管理后台的使用方法。安装和部署请参阅[部署指南](deployment.md)。

## 1. 首次设置

用浏览器打开 `http://<服务器地址>:17520/`，输入管理后台密码登录（首次使用的初始密码在服务器的 `data/initial-password.txt` 中，登录后请在「设置 → 管理后台」中修改）。

首次登录会打开**新手引导**：扫码登录 B站 → 填直播间 → 选手机竖屏还是电脑横屏、用哪个直播软件，按步骤加到直播软件里 → 发一个测试特效。扫码可以先跳过，之后在左下角点账号再扫；特效页还没连上时，最后的按钮写「先到这里」，不会说「设置完成」。之后也可以在「设置」页的右上角重新打开。总览顶部的「开始使用」清单，特效页连上过一次就算完成，之后先打开星临、还没开直播软件时不会再冒出来。

### 1.1 登录 B 站账号

在「设置 → B站账号」中，用 B 站手机客户端扫描二维码登录。

- 星临只用这个账号**读取**直播间消息（观众的昵称、身份、弹幕、礼物），不会发弹幕、不会送礼。
- **建议使用小号**，不要用主播本人的账号。
- 登录信息加密保存在星临里，有效期约 30 天；剩 3 天以内时后台顶部出黄色提醒，失效后出红色提醒，点「重新扫码」就能扫。

### 1.2 设置直播间

在「设置 → 直播间」中填写房间号，短号、长号都可以。星临会自动查出主播信息。

「设置 → 播放 → 连接直播间」默认为**只在开播时**：没开播时只用公开接口每分钟查一次开播状态，账号不在线；开播后才用账号连接直播间。

### 1.3 接入直播软件

在「直播软件输出」页选择你使用的直播软件，确认画布方向和分辨率，然后复制页面上的**浏览器源地址**。

**B 站直播姬**

1. 竖屏直播时，先在直播姬里切换到竖屏直播模式。
2. 点「添加素材」，选择浏览器（网页）类素材。
3. 地址栏粘贴浏览器源地址，宽高填写与画布一致的数值（竖屏默认 1080 × 1920）。
4. 拖动素材铺满画面，并放到图层最上方。

**OBS Studio**

1. 竖屏推流时，在「设置 → 视频」中把基础分辨率设为 1080 × 1920。
2. 在「来源」中点 +，选择「浏览器」，命名为「星临特效」。
3. URL 粘贴浏览器源地址，宽度、高度填写与画布一致的数值。
4. 勾选「通过 OBS 控制音频」，特效的音效才会进入直播。
5. 取消勾选「不可见时关闭源」和「场景变为活动状态时刷新浏览器」，避免切换场景时漏播。
6. 把「星临特效」拖到来源列表最上方。

添加完成后，「直播软件输出」页会显示特效页已在线，以及它运行在什么环境中。首次使用建议先用浏览器源打开页面上的**兼容性自检页**，确认特效和声音都正常。

星临更新后，已经打开的特效页会在当前特效播完、空闲 2 秒后自动刷新成新版本，不需要手动刷新浏览器源。管理后台不会自动刷新：有新版本时页面顶部会提示，点「刷新」即可。

> 浏览器源地址中带有访问密钥，请不要公开。泄露后可以在「直播软件输出」页重置密钥，旧地址会立即失效。

需要竖屏直播、横屏录播等多种画面时，可以新建多个输出，每个输出有自己的地址和画布设置，播放内容保持同步。

**弹幕列表**

弹幕列表把直播间里所有人的弹幕排成一列显示在直播画面上（默认最多 8 条，可以自己设，新的从下面进来）。它是同一个输出的另一个地址，在「直播软件输出」页的「弹幕列表」里复制：

1. 在直播软件里再添加一个浏览器（网页）素材 / 来源，命名为「星临弹幕」。
2. 粘贴弹幕列表地址，宽高按后台「宽高填」写的数值填（默认 8 条是 **600 × 900**；改了条数或字号，建议高度会跟着变，矮了就少显示几条）。
3. 拖到画面左边或右边。想改大小请改宽高数字或后台的「字号」，不要直接拉伸，否则会变形。

在「弹幕列表设置」里可以设最多显示几条（1 – 20，默认 8），选靠左或靠右对齐（放在右边时选靠右，头像跟着换到右边）、字号，以及粉丝牌只显示本直播间的还是戴什么显示什么。想让弹幕在没人说话时自己消失，打开「自动消失」，选没人发弹幕多久后开始消失：到时间后从最上面最旧的那条开始，每 2 秒淡出一条，有新弹幕来就重新计时（默认关着：一直显示，只被新弹幕顶走）。不用时关掉右上角的开关，直播画面上就不再显示。弹幕列表不受触发规则、黑名单和「暂停所有特效」影响。

**送礼名单**

送礼名单把本场直播收到的礼物、上舰、醒目留言排成一列显示在直播画面上，样子和礼物特效的彩色横条一样（礼物按价值变色；大航海成员送的礼物、醒目留言和上舰按身份配色：舰长蓝、提督紫、总督红金；礼物图是动图，大航海送的头像带头像框）。按时间先后排成一串，一屏默认 6 条；礼物多了放不下时，整串从下往上慢慢循环滚动（像片尾字幕），首尾接在一起一直滚，新收到的会从下边缘滚进来。连着送同一种礼物合成一条，显示总数；免费礼物不显示。它也是同一个输出的另一个地址，在「直播软件输出」页的「送礼名单」里复制：

1. 在直播软件里再添加一个浏览器（网页）素材 / 来源，命名为「星临送礼名单」。
2. 粘贴送礼名单地址，宽高按后台「宽高填」写的数值填（默认 6 条是 **640 × 650**）。
3. 拖到画面一侧。想改大小请改宽高数字或后台的「字号」，不要直接拉伸。

设置都在左侧的 **「送礼名单」** 页面（右上角有开关和「复制地址」）。最上面先选 **「名单放什么」**：
- **自动：本场收到的**：直播时收到的礼物自动加进来。下面再选「全部礼物」（所有付费礼物）或「只要这几种」（从你直播间的礼物面板里点选礼物种类，例如只看心动盲盒，谁送的都算）；上舰、醒目留言可以单独打开或关掉。
- **手动：我挑的记录**：只显示你挑出来的那几条（谁送的哪一次），本场新收到的不会进来。选了它，下面会出现「送礼记录」：默认是「全部场次」，在保留期内的所有记录里一起找，也可以只看某一场；可以搜观众名、UID、礼物名或醒目留言内容，还能按金额筛（1 / 10 / 50 / 100 / 500 元以上），找到了点「加入名单」（全部场次一次最多列 500 条，太多时加上条件缩小范围）；也可以在「事件记录」里点一条礼物、上舰或醒目留言的「⋯」→「加入送礼名单」。「名单里的记录」可以调顺序、移出，最多 50 条，一直保留（跨场次也不清空，事件记录过了保留期被删掉也照样显示），直到你移出。配合「不滚动」就能把特定礼物一直挂在画面上。

选项下面有一行 **「现在画面上显示」**，用一句话写出直播画面上会显示什么；会显示空名单（例如「只要这几种」却还没选礼物）时标红提醒。右边是预览和 **外观**：滚动（不滚动 / 慢 / 中 / 快，默认中，约 3 秒一条；「不滚动」时固定挂着，放不下只留最新的几条）、靠左或靠右、字号、一屏显示几条（1 – 20）。

「自动」的名单按场算：开播后显示这一场的，下播后继续显示刚结束的那一场，下次开播自动清空；服务重启、页面刷新都不会丢。送礼名单不受触发规则、黑名单和「暂停所有特效」影响。预览下面点「测试一条」可以看样子（只在预览里显示）。

**点歌窗口**

观众弹幕点的歌在点歌窗口里播放（声音也从这里出来），同时显示正在放的歌、滚动歌词和接下来几首。它也是同一个输出的另一个地址，在「直播软件输出」页的「点歌窗口」或「弹幕点歌」页右上角复制：

1. 在直播软件里再添加一个浏览器（网页）素材 / 来源，命名为「星临点歌」。
2. 粘贴点歌窗口地址，宽高填 **640 × 560**（字号选「大」时 800 × 700）。
3. OBS 里勾选「通过 OBS 控制音频」，歌的声音才会进入直播；在混音器里可以单独调这个来源的音量。
4. 拖到画面一侧。

加了好几个点歌窗口（比如竖屏、横屏各一个）也只有一个出声音，不会两首叠在一起。用「在浏览器里查看」打开的页面只显示、不出声。怎么点歌、规则和外观见 [4.5 弹幕点歌](#45-弹幕点歌)。

## 2. 触发规则

「触发规则」页分为**进场、专属用户、弹幕、礼物、上舰**五个标签，标签上的数字是「开着几条 / 一共几条」。每条规则占一行，开关、条件、播放的特效、冷却各占一列，上下对齐。改动立即生效。每个标签顶部有一句说明，点「怎么判断」可以看详细的规则。

- 点 ▶ 在预览小窗中播放效果（使用真实的特效页，只在这里播放，观众看不到）；小窗中的「发送到直播测试」会真的播放到直播画面上。
- 选特效的下拉框里，每个特效都有缩略画面，下面写着现在用在哪里；点右边的 ▶ 只预览，不会改规则，关掉预览后列表会自动再打开。特效多于 10 个时可以搜索名字。
- 点右上角的「模拟一下」，假装发生一件事（例如一位 21 级粉丝牌的观众进场），查看会使用哪条规则、播放什么，不会真的播放，也不会记录。进场会一步步写出找规则的过程（专属用户 → 身份 → 粉丝牌 → 荣耀等级 → 其他观众，哪条关着被跳过）。身份可以选「主播本人」，也可以选「某位观众」填 UID（能直接选专属用户），测专属特效和弹幕规则里的「指定观众」。
- 每条规则都可以单独开关；关闭后，这部分观众按下一条符合的规则处理。例外：礼物某一段关掉后，这一段的礼物直接不播（不会改用更低的一段）；粉丝牌某一段关掉后，这些观众接着按荣耀等级、再按「其他观众」处理；荣耀等级某一段关掉后，这些观众按「其他观众」处理。
- 删除规则、删除某一段、移除专属用户、加入黑名单等操作后，提示条上有「撤销」按钮，8 秒内点它就能恢复。
- 开关在每行最左边；关掉的行会变淡，鼠标停在上面会说明关掉后这些人按什么处理。每行右边是「预览 ▶」和「⋯」，不常用的操作（上下移动、删除、调整这个特效）都在「⋯」里。弹出的选择框和菜单都可以按 Esc 关闭。

### 2.1 进场

有人进场时，按以下顺序查找，使用**第一条**符合的规则：

**专属用户 → 大航海（总督、提督、舰长）→ 房管 → 粉丝牌 → 荣耀等级 → 其他观众**

- **专属用户**：为指定的观众设置单独的特效，永远最先使用，可以设置有效期（例如生日当天）。在单独的「专属用户」标签里添加和管理；进场表格最上面一行会提示现在有几人。在总览的实时动态中点某位观众，也可以直接设置。
- **大航海**、**房管**：只算本直播间的身份。
- **粉丝牌**：只算本直播间的牌子，按等级分段，每一段放一种特效。点「粉丝牌」右边的「＋ 加一段」，输入等级即可再分出一段；删掉某一段在这一行的「⋯」里。
- **荣耀等级**：B站账号自己的荣耀等级（在 B站花得越多越高，和在不在你的直播间消费无关），用来照顾没戴你粉丝牌的「路人大佬」。戴着本直播间粉丝牌的人按粉丝牌算，不看荣耀等级。默认只有「50 级及以上」一段，先关着，其他等级点「＋ 加一段」自己加；给某一段选好特效就会自动打开（没选特效打不开）。低于最低一段的人按其他观众处理。加一段、删一段的做法和粉丝牌一样，可以一段都不留。
- **其他观众**：以上都不符合的观众，默认关闭。直播间人多时建议保持关闭，以免刷屏。

**不重复播放的方式**（进场标签右上角）：

- **按时间**：每条规则单独设置「同一个人多久内只播一次」，可选每次都播、1、5、10、30 分钟、1 小时，或自定义。
- **每场直播只播一次**：同一个人在一场直播中只播放一次，下一场重新计算。

### 2.2 弹幕

观众发的弹幕里有指定的关键词时播放特效。

- 匹配方式：「包含」（弹幕里有这个词就算）或「整条就是」（整条弹幕只能是这个词，例如「晚安」不包括「晚安~」）。英文不分大小写，全角半角字母也当成一样。
- 可以限定谁发的才算（可以多选，满足任意一项就算）：所有人、主播、房管、总督、提督、舰长、戴本房间粉丝牌且不低于某一级、荣耀等级不低于某一级、指定观众（填 UID，也可以从「最近发弹幕的人」里点选）。新建的规则默认只算主播、房管和总督、提督、舰长发的，可以再改。去掉「指定观众」的勾会清空名单，提示条上可以撤销。
- 「主播本人不触发」「登录的 B 站账号不触发」（在「设置」里，默认关着）开着时，主播、登录的账号发的弹幕默认不触发；规则里勾了「主播」或者填了 TA 的 UID，就照样触发。手动拉进黑名单的人，怎么设置都不触发。
- 关键词输入后按回车，或者点别处，就会添加；一次输入多个词时用逗号、顿号或空格隔开。一条规则最多 20 个关键词。
- 点「新建弹幕规则」会先出现一张草稿卡，填好关键词点「添加」才保存，没填完的规则不会在直播里起作用。
- 可以分别设置**所有人合计**多久内只播一次（不管谁发）、**同一个人**多久内只播一次，防止刷屏；选「每次都播」就不限制。
- 多条规则都符合时，使用编号最小（排在最上面）的一条；按住左边的编号拖动，或者在「⋯」里选「往上挪 / 往下挪」调整顺序。
- 还没有弹幕规则时，页面会提供「生日快乐」「晚安」「签到」「主播好」等常用例子，点击即可添加。

### 2.3 礼物

- **指定礼物**：从本直播间的礼物面板中选择礼物，送出这些礼物时优先使用这里的特效。礼物按编号匹配，同名不同价的礼物可以区分开。选择面板选完一个不会收起，可以连着选几个。
- **按价值**：其余礼物按一次送出的总价值（单价 × 数量）分段，每一段放一种特效。刻度条展示了每一段的金额范围和对应特效；低于最低一段的礼物不播放。点表格下面的「＋ 加一段」可以再分一段。
- **连击合并**（礼物标签右上角）：同一个人在设定的几秒内连续送同一种礼物，合并为一次特效，显示总数量。
- **B站动画**：内置特效「B站·礼物动画」会播 B站自己的礼物全屏动画（例如送「极速超跑」时满屏跑的车，大多是 5 元以上的礼物才有），画面上方显示是谁送的、送了几个，时长跟着动画走。没有动画的礼物按价值显示：100 元以上用「晶·大礼物」，以下用「晶·礼物」，放在左下（弹幕区上面）。默认 10 元以上的两段都用它（礼物规则新安装时都是关着的，要在「触发规则 → 礼物」里打开）。注意：观众在 B站 App 里看直播时，App 自己也会播这个动画（观众没关礼物特效的话），所以会看到两遍；不想重复就给这一段换成别的特效。动画从 B站读取，直播电脑连不上 B站的图片服务器或者太卡（不支持 WebGL）时，只显示上面那一条，并在日志里记下原因。
- **礼物图用动图**（礼物标签右上角）：礼物特效里的礼物图用 B站的动图，关掉用静态图。对所有礼物特效都有效，直播电脑比较卡时可以关掉。
- 免费礼物不触发特效。

### 2.4 上舰

有人开通或续费大航海时播放。总督、提督、舰长各一行，开通、续费各占一列。续费默认「和开通时一样」，点它就能单独选一个特效；想改回去，在「⋯」里选「续费改回和开通一样」。上舰特效默认插队优先播放。

## 3. 素材库

素材库中的每一项都是一个可以在规则里选用的特效。

- **内置素材**：随星临提供，不能直接修改。点「复制并编辑」可以在副本上自由调整。

  | 素材 | 风格 | 默认用在 |
  |---|---|---|
  | 宫·总督 / 宫·提督 / 宫·舰长 | 东方宫廷 | 总督 / 提督 / 舰长的进场和上舰 |
  | B站·礼物动画 | B站自己的礼物全屏动画，上方一条谁送的；没有动画的礼物按价值显示晶·大礼物或晶·礼物 | 礼物 100 电池（10 元）以上（默认关闭） |
  | 晶·大礼物 | 和晶·礼物一样的横条，星光碎片多一些 | （B站·礼物动画里没有动画的 100 元以上礼物） |
  | 晶·礼物 | 彩色渐变横条，按价值变色（蓝、紫、粉、金，和 B站连击条一样），大航海成员送的按身份配色（舰长蓝、提督紫、总督红金）；礼物图（动图）放大、后面转着光芒、迸出星光，数量大号斜体砸进来；大航海送礼时头像自动套上头像框 | （B站·礼物动画里没有动画的 10 ~ 100 元礼物） |
  | 晶·房管进场 | 玻璃质感，带「房管」标签 | 房管进场 |
  | 晶·弹幕 | 玻璃质感气泡，显示弹幕内容 | 新建弹幕规则时的默认特效 |
  | 霜·粉丝进场 / 霜·普通进场 | 磨砂玻璃条，带粉丝牌 | 粉丝牌进场 / 普通观众进场（默认关闭） |
  | 字·一行 | 只有一行文字 | 礼物 10 ~ 100 电池（1 ~ 10 元，默认关闭） |
- **我的素材**：把文件拖到素材库页面的任何地方即可上传，支持透明 WebM（推荐）、MP4（没有透明背景，会挡住画面）、SVGA、Lottie（.json）、GIF、PNG、APNG、WebP、JPG，单个文件不超过 100 MB。格式不对、太大的文件会直接提示（例如 MOV 视频要先转成 WebM）。没传上去的文件会留一张红色卡片写明原因，可以重试或移除。上传成功的提示条上有「去触发规则里用上它」。

- 正在被规则使用的素材不能删除。

卡片上显示素材的真实画面：内置特效是它播放到最完整那一刻的截图，视频显示中间的一帧（鼠标停上去从头播放），SVGA、Lottie 显示中间一帧。鼠标停在卡片上，右上角会出现 ▶，点它按素材平时的用途预览。素材库里每张卡片底部有「重命名」「复制」「删除」按钮：重命名直接在卡片上改，按回车保存、Esc 取消；删除要点两次确认，正在被触发规则使用的素材不能删。音效卡片也可以重命名。

点开一个素材可以设置：① 画面 ② 位置和大小 ③ 头像和欢迎语 ④ 音效 ⑤ 时长和渐入渐出，左边可以实时预览（包括还没保存的修改）。打开窗口和改设置时预览自动重播，但不出声，想听声音点「重播（带声音）」。预览默认按素材平时的用途播放（礼物特效带礼物图和数量，弹幕特效带弹幕内容），预览下面可以切换按「进场 / 弹幕 / 礼物 / 上舰」预览，示例观众可以换成总督、舰长、普通观众或长昵称；「发送到直播测试」发的就是预览里的样子，没保存的修改也能测。点「保存」后窗口不关，可以接着调；有没保存的修改时关窗口会先问你。欢迎语下面的按钮写着「昵称」「礼物名」「数量」等，点一下插入到欢迎语里，下面实时显示效果。视频、SVGA、Lottie、动图默认按文件本身的时长完整播放；想让它提前结束，打开「手动设置时长」填秒数（最长到素材本身的长度）。静态图片直接设置显示几秒。上传的素材还可以分别打开「开头渐入」「结尾渐出」，新上传的默认关闭；打开后可以填渐入、渐出各用几秒（0.1 ~ 5 秒）。叠加的头像和欢迎语只显示约 4.5 秒。打开「大航海头像框」后，舰长、提督、总督的头像会套上 B 站的头像框。打开「荣耀等级勋章」后，观众昵称前面会放上 B 站的荣耀等级勋章（和 B 站弹幕里的一样，每一级一张图），没有荣耀等级的观众不显示；内置样式也能用（先「复制并编辑」）。上传的素材选好位置后还可以再挪：在左边预览里按住素材拖到想要的地方，或者用「上下挪动」「左右挪动」滑块微调（按画面宽、高的百分比算，横屏竖屏都一样），「回到原位」清零；挪进顶部信息栏、底部弹幕区时会提醒。「大小」滑块可以把素材放大或缩小（20% ~ 200%，100% 是自动算出的大小：选「居中」时铺满画面，选左下、右下、顶部时会自动缩小到画面高度的 45% 以内）。点弹窗左上角的素材名称（旁边有铅笔图标）就能改名。「① 画面」里点开「边缘慢慢变透明（上下羽化）」，可以让视频的上下边缘慢慢变透明：默认「跟随全局」（在「设置 → 素材显示」统一开关和调宽度，新安装时默认打开、宽度 10%，只对没有透明通道的素材生效），也可以「自己设置」宽度或选「不羽化」。

**SVGA 动态图层**：SVGA 特效里可以预留图层，播放时换成进场观众的信息。上传 SVGA 后，素材设置「① 画面」里会列出所有图层，每个图层选一项：头像（圆形 / 方形）、头像框（舰长、提督、总督的 B 站头像框）、身份图标（船锚）、昵称、欢迎语，或者不替换。头像框和身份图标只给大航海观众显示，其他观众这一层会藏起来；昵称、欢迎语放不下时自动缩小字号。

找设计师做 SVGA 时，可以请对方把图层（图片的名字）按下面命名，上传后会自动对应好：

| 图层名 | 换成 | 建议 |
|---|---|---|
| `avatar` | 头像（圆形） | 正方形占位图，例如 200×200 |
| `frame` | 头像框 | 正方形，约为头像的 1.4 倍，和头像同一个中心 |
| `badge` | 身份图标（船锚） | 正方形，例如 64×64 |
| `honor` | 荣耀等级勋章 | 扁长方形，按 36×16 的比例，例如 108×48；勋章按原比例放在中间，没有荣耀等级的观众这一层会藏起来 |
| `nickname` | 昵称 | 按想要的文字区域大小做一张占位图，文字画在里面、居中 |
| `welcome` | 欢迎语 | 同上 |

买来的 SVGA 图层名常见的写法（head、头像、nick、name、kuang 等）也会自动识别，识别不了的可以自己选。

## 4. 直播中

### 4.0 顶部提醒

会让特效播不出来的情况，所有页面顶部都会出提醒条，点按钮就能去处理：

- **正在直播，但特效页没连上**（红色）：直播软件里的特效页断开超过 20 秒。点「去检查」到「直播软件输出」页。顶栏也有一个「特效页在线 / 不在线」的小灯。用「在浏览器里查看」打开的页面不算在线：它照样能看到特效，但直播画面里没有。
- **B站登录失效 / 已过期**（红色）：收不到直播间的消息，点「重新扫码」直接扫码登录。登录剩 3 天以内时先出黄色提醒，可以点「知道了」收起。
- **和星临的连接断了**（黄色）：断开超过 5 秒才提醒，会自动重连；这时页面上的状态可能不是最新的。

### 4.1 总览

- **直播间**：正在监控的直播间、主播、标题、分区，以及 B 站记录的开播时间和已播时长。
- **数据**：默认显示本场；没开播时显示上一场（从开播算到下播，23 点播到凌晨 1 点也是完整的一场，不会被 0 点切开），可以手动切换到「今天」（0 点至今）。一排 6 个数字：进场人数（去重）、触发特效次数，以及 B 站的看过人数、高能榜人数、点赞数、粉丝数。
- **实时动态**：最新的进场、弹幕、礼物、上舰、醒目留言，以及是否播放了特效（醒目留言现在只记录，不触发特效）。可以只看某一种（进场 / 弹幕 / 礼物和醒目留言 / 上舰），或者打开「只看大航海」（从最近 150 条里挑，更早的去「事件记录」查）。鼠标停在列表上时暂停滚动，方便点人，移开后再显示新来的。点任意一行可以为这位观众设置专属特效、复制 UID 或加入黑名单。
- **右侧面板**有 4 个标签，选过的会记住：
  - **播放队列**：正在播放的一条（带进度）和排队中的特效（大约多久后播放）。可以跳过当前、把某一条移出队列，或清空排队；「排队设置」中可以调整高价值插队和最多排队条数。标签上显示条数（绿色表示正在播放），没有时显示「空闲」；有特效播放时不会自动切换过来。
  - **在线观众**：在线人数和在线名单（和 B 站直播间里的「在线观众」一样），按贡献排序（单位是电池），还没有贡献的观众也在，每 30 秒刷新。B 站最多只给前 100 位；隐身、没登录 B 站的观众不在名单里。可以只看大航海或戴本房间粉丝牌的。
  - **礼物榜**：这段时间（本场 / 今天，跟着上面的数据范围）每人花了多少（电池，小字是金额）：付费礼物、上舰（按实际支付的价格，有折扣的按折扣价）、醒目留言都算。盲盒按开出来的礼物算，和 B 站高能榜一样。每行写着送了几次、最贵的一件，有上舰、醒目留言的会标出来。和 B 站高能榜上的电池数比，可能差几个电池：B 站还给点赞、发弹幕加少量的分。
  - **大航海**：这段时间来了哪些舰长、提督、总督，各进场几次、最后一次什么时候；加上 B 站的舰队名单，显示「舰队 N 人，来了几人」，点开「还没来的」能看到没来的人（舰队名单 15 分钟更新一次，人特别多时只读前 1200 人）。
  - 名单里点任意一行，和实时动态一样，可以设置专属特效、复制 UID 或加入黑名单。
- **身份构成**：进场观众的身份比例，下面是荣耀等级分布（每人按最后一次进场时的等级）。

数据按直播间分别统计，切换直播间后显示新直播间的数据。

### 4.2 素材快捷播放

把常用的素材做成按钮，直播时点一下（或按快捷键）马上在直播画面上播放，不用再发弹幕触发。

- **在哪里**：左侧导航「素材快捷播放」是大按钮；「总览」上也有一排小按钮。在命令面板（`Ctrl + K`）里搜按钮名字也能播。
- **怎么播**：点按钮马上播放。正在播的观众特效（比如舰长进场）会先停下，等快捷播放的素材播完，再从头播一遍，不会丢；连着点两个按钮，后一个直接换掉前一个。快捷播放不显示欢迎语，也不算进统计和事件记录。已暂停所有特效、或者特效页不在线时播不出来，按钮上方会写明原因。
- **设置按钮**：点「编辑按钮」，可以添加任意素材、改按钮上的名字（不填时显示素材名）、拖动或用箭头调整顺序、删除按钮（素材本身不会删）。改完点「保存」。素材在素材库里删掉后，对应的按钮也一起删掉。第一次使用时，会自动把弹幕规则里用到的素材放进来。
- **快捷键**：编辑时点「设快捷键」，再按一个数字或字母（小键盘数字也可以）；按 Backspace 清掉。快捷键只在「素材快捷播放」或「总览」页面是当前窗口时有用，在输入框里打字时不会触发。
- **全局快捷键（桌面版）**：在桌面版窗口里编辑时，每个按钮还有「设全局快捷键」：按住 Ctrl、Alt 或 Shift 再按一个数字、字母或 F1–F12（例如 Ctrl+Alt+1）。全局快捷键在直播姬、游戏等别的窗口里按也能播放；被别的软件占用时，保存后会提示换一个组合。服务器版和用浏览器打开的后台没有这一项。

### 4.3 暂停与播放顺序

- **紧急暂停**：点顶部的「暂停所有特效」，或按 `Ctrl + Shift + P`。直播画面上的特效立即停止，排队中的特效被清空，事件照常记录；页面顶部会一直显示「所有特效已暂停」。快捷键只负责暂停（慌忙中多按一次也不会变成恢复）；恢复请点「恢复播放」。
- **播放顺序**：上舰 → 礼物 → 进场 → 弹幕。上舰和 1000 电池（100 元）以上的礼物可以插队（可在「排队设置」中关闭）。排满后，先挤掉顺序最靠后、最早进来的一条。

### 4.4 事件记录

每个事件都会记录：发生时间、观众、命中了哪条规则、播放的特效，以及没有播放的原因，例如：

| 状态 | 含义 |
|---|---|
| 已播放 / 排队中 | 正常 |
| 未命中规则 | 没有符合的规则，或规则已关闭 |
| 冷却中 | 在「多久内只播一次」的时间内 |
| 本场已播过 | 开启了「每场直播只播一次」 |
| 黑名单 | 这位观众在黑名单中 |
| 未开播 | 没有开播，且未开启排练模式 |
| 已暂停 / 已清空 | 暂停或清空队列时还没播放 |
| 特效页不在线 | 当时没有特效页连接 |
| 队列已满，丢弃 | 排队条数达到上限 |

可以按事件类型筛选，按状态筛选（也可以只看某一种没播的原因，例如只看「特效页不在线」），按时间筛选（今天、本场、最近 7 天），或按昵称、UID 搜索；有筛选时可以一键「清除筛选」。鼠标停在状态上会显示大白话的原因；鼠标停在这一行时，状态旁边会出现处理按钮：未命中规则 → 去看规则，特效页不在线 → 去检查特效页，冷却中 → 去改，未开播 → 去设置，黑名单 → 移出黑名单。在实时动态、事件记录里点观众，菜单里有「查看 TA 的事件记录」。

每个事件占一行：时间、观众、身份、事件、结果。「结果」第一行是播放状态（绿点为已播放），第二行是命中的规则和播放的特效。没播的那一行，鼠标停上去会出现处理按钮（例如「去看规则 →」）。右上角打开「**只看命中规则的**」，会隐藏「未命中规则」的记录（大部分观众本来就不触发特效，直播时这类记录最多；醒目留言也会一起隐藏），这个开关会记在这台电脑上。每行右边的「⋯」里有：设为专属（进场）、只看 TA 的记录、复制 UID、加入黑名单。

### 4.5 弹幕点歌

观众发弹幕「**点歌 歌名**」（写上歌手更准，例如「点歌 晴天 周杰伦」），歌会排进列表，在直播画面上的点歌窗口里一首接一首地放。左侧导航 **「弹幕点歌」** 页右上角是总开关（新安装时关着）。

**观众能发的指令**（都可以在「规则」里改）：
- 「点歌 歌名」：点歌。写成「点歌：晴天」「点歌《晴天》」也认得。点到了会提示排第几首、大约多久后放（主播暂停了、没开播、没加点歌窗口时如实说明，不会说「马上播放」）；没点到会说明原因。同一个人一分钟内反复失败、「点得太快了」这类提示只在后台显示，不刷直播画面。
- 「切歌」：切掉正在放的。点这首歌的人、房管能切（可以关掉），主播一直能切。
- 「取消点歌」：撤掉自己点的、还没放的那首。
- 「我的歌」：看自己点的歌正在放、排第几、还要等多久（同一个人 15 秒内只回一次）。

**歌从哪里找**：
- **网易云音乐**：不登录也能放免费歌。在「规则 → 歌从哪里找」扫码登录网易云会员账号后，会员歌也能完整播放。数字专辑这类要单独购买的歌放不了。
- **本地歌库**：在「歌库」里上传音乐文件（mp3、flac、m4a、ogg、wav，一次能选多个）。歌名、歌手、封面、歌词从文件里读，读不到歌名时按文件名「歌手 - 歌名」猜，可以直接在列表里改。歌词也可以放一个和音乐文件同名的 .lrc 一起上传，或者点某首歌的「配歌词」。桌面版还可以直接选电脑上的一个文件夹（包括子文件夹），不用上传，文件夹里加了、删了歌点「重新扫描」。
- 两个都开时，默认先在本地歌库里找，没有再找网易云（可以改）。

**怎么选歌**：按搜索结果挑最合适的一首。写了歌手的，歌手要对得上（翻唱、伴奏、名字里蹭歌手名的不算），网易云上没有这位歌手的版本时提示「没有找到 xx 的版本」，不会随便放一首翻唱。只写歌名的，优先原版，伴奏、纯音乐不收（观众自己写了除外）。最相关的那首是会员歌、又没登录会员时，只换同一位歌手的其他版本，没有就提示「需要会员」。

**规则**：谁能点歌（和弹幕规则一样的选法，默认所有人；主播不受限制）、每人同时最多排几首（默认 1 首，正在放的不算）、同一个人两次点歌的间隔（默认 30 秒）、同一首歌放过之后隔多久才能再点（默认 30 分钟）、列表最多几首（默认 20）、歌最长多久（默认 7 分钟）、大航海点的歌排在普通观众前面（默认开）、下播自动暂停（默认开：没开播时不放，开播后接着放）。还可以设不收的歌（歌名或歌手里有某些字）和不让点歌的观众。

**播放**页：
- 正在放的歌、暂停 / 继续、切歌、音量。
- 列表：拖动左边的序号调整顺序，「↑」排到下一首，「×」删掉，「清空」清掉还没放的；删掉、清空都能在提示里撤销。每首歌的「⋯」里可以「不让 TA 点歌」「这首歌以后不收」（列表里相关的歌一起删掉，也能撤销）。「历史」页的每一行也有这两项。
- 全局快捷键（桌面版）：可以给「切歌」「暂停 / 继续」各设一个组合键（例如 Ctrl+Alt+N），在直播姬、游戏等别的窗口里按也能用；不能和快捷播放按钮的重复。
- 加歌：搜本地歌库和网易云，点「下一首」或「加到最后」（不受点歌规则限制）。
- 模拟点歌：用「测试观众」的身份按规则点一次，不用开播；点到的歌会真的进列表。
- 最近的点歌消息。

**画面**页：预览（不出声），六种样子：**流光**（封面的颜色铺满卡片，像音乐 App 的播放页）、**手帐**（日系：方格纸、和纸胶带贴着拍立得风格的封面，歌名像荧光笔划过，一支小铅笔沿着进度写过去，手写字体）、**灵动岛**（玻璃小胶囊，后面的画面透出来；换歌、有人点歌时弹性展开显示提示），以及最早的三种：**玻璃卡片**（封面 + 封面颜色的柔光）、**黑胶唱片**（唱片转动，暂停时唱臂抬起）、**细长胶囊**（一行，占地方最少），颜色都跟着封面变；「接下来」每首歌前面有小封面；另外还有靠左或靠右、字号、显示接下来几首（0 – 5）、滚动歌词（外文歌可以同时显示中文翻译）。**声音**：音量；有带声音的特效（配了音效或有声音的视频）在播时，音乐自动调小（默认调到 30%），播完慢慢恢复。

**历史**页：放过的歌（放完、切掉、取消、放不了和原因），可以「再点一次」；最近 30 天点得最多的歌、点歌最多的观众。记录的保留天数和事件记录一样。

**总览页**：打开点歌后，总览上有一张点歌小卡片：正在放的歌、进度、「暂停 / 继续」「切歌」，以及列表还有几首。命令面板（`Ctrl + K`）里也能搜「切歌」「暂停点歌」。换歌、切歌、暂停时声音会淡出淡入，不会突然断掉。网易云登录失效时，后台顶部会出现提醒。

**什么时候不放**：点歌关着、在「播放」里点了暂停、没开播（打开了下播自动暂停）、直播软件里没加点歌窗口。这时正在放的歌停在原处，恢复后接着放；页面顶部会写明原因。没开播时点「现在就放」可以先放着（这次下播前不再自动暂停）。

> 直播里放有版权的歌，B站可能会提示或静音，请自己留意。网易云的播放地址用的是网页版的接口，网易云改了接口时可能暂时放不了，星临会在点歌消息里提示「获取播放地址失败」。

## 5. 设置

| 分组 | 内容 |
|---|---|
| **B站账号** | 扫码登录、登录状态与剩余有效期、退出登录 |
| **直播间** | 房间号（短号、长号都可以） |
| **播放** | 未开播时（不播放 / 照常播放，用于排练）；连接直播间（只在开播时 / 一直连接） |
| **黑名单** | 这些观众不会触发任何特效，事件照常记录；主播本人、登录的 B 站账号是否触发 |
| **管理后台** | 修改登录密码 |
| **数据** | 每天自动备份（保留 7 份）、立即备份（另外保留 5 份）、事件记录保留天数、导出 / 导入配置 |

页面右上角可以重新打开新手引导。

**导出 / 导入配置**：导出的配置可以包含素材文件，用于备份或迁移到另一台电脑、服务器。导入前会先显示有哪些变化，确认后才生效；确认时会先自动备份一份现在的配置。备份列表里每一份都有「恢复到这份」，同样先显示变化、确认后才生效，导错了可以用它恢复回来。

## 5.1 关于

左侧导航「其他」里的「关于」：

- **版本和更新**：现在的版本号，是服务器版还是桌面版；运行的是还没发布的开发中代码时，会标出「开发版」和提交编号。点「检查更新」会查有没有新的正式版（每小时最多自动查一次；国内网络可能连不上，稍后再试即可）。有新版本时，服务器版在服务器上运行 `starfall update` 更新。
- **运行信息**：已经运行多久、系统、内存占用、数据目录、数据库 / 素材 / 备份各占多少空间。遇到问题时点「复制运行信息」，和问题描述一起发邮件给作者。
- **更新记录**：每个版本改了什么，点版本号展开。
- 作者和联系邮箱。

## 6. 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl + K` | 打开命令面板：搜索页面、预览某个身份的进场特效、快捷播放素材、暂停 / 恢复、清空队列等 |
| 数字或字母 | 「素材快捷播放」「总览」页面里，播放设了这个快捷键的按钮（见 4.2） |
| `Ctrl + Shift + P` | 暂停所有特效（恢复请点按钮） |
| `Esc` | 关闭弹窗、预览小窗、素材设置（有没保存的修改时会先问） |
| `Ctrl + S` | 素材设置里保存 |

## 7. 在手机上使用

管理后台适配手机，用手机浏览器打开同一个地址即可，底部有导航栏。直播中可以随时暂停特效、查看实时动态、设置专属用户。
