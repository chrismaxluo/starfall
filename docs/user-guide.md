# 使用手册

本文介绍星临管理后台的使用方法。安装和部署请参阅[部署指南](deployment.md)。

## 1. 首次设置

用浏览器打开 `http://<服务器地址>:17520/`，输入管理后台密码登录（首次使用的初始密码在服务器的 `data/initial-password.txt` 中，登录后请在「设置 → 管理后台」中修改）。

首次登录会打开**新手引导**，按顺序完成三步即可开始使用。之后也可以在「设置」页的右上角重新打开。

### 1.1 登录 B 站账号

在「设置 → B站账号」中，用 B 站手机客户端扫描二维码登录。

- 星临只用这个账号**读取**直播间消息（观众的昵称、身份、弹幕、礼物），不会发弹幕、不会送礼。
- **建议使用小号**，不要用主播本人的账号。
- 登录信息加密保存在服务器上，有效期约 30 天；快到期时，左下角会提醒重新扫码。

### 1.2 设置直播间

在「设置 → 直播间」中填写房间号，短号、长号都可以。星临会自动查出主播信息。

「设置 → 播放 → 连接直播间」默认为**只在开播时**：没开播时只用公开接口每分钟查一次开播状态，账号不在线；开播后才用账号连接直播间。

### 1.3 接入直播软件

在「直播软件输出」页选择你使用的直播软件，确认画布方向和分辨率，然后复制页面上的**浏览器源地址**。

**B 站直播姬**

1. 竖屏直播时，先在直播姬里切换到竖屏直播模式。
2. 点「添加素材」，选择浏览器（网页）类素材。
3. 地址栏粘贴浏览器源地址，宽高填写与画布一致的数值（竖屏默认 1080 × 1920）。
4. 拖动素材铺满画面，并放到图层最上方。

**OBS Studio**

1. 竖屏推流时，在「设置 → 视频」中把基础分辨率设为 1080 × 1920。
2. 在「来源」中点 +，选择「浏览器」，命名为「星临特效」。
3. URL 粘贴浏览器源地址，宽度、高度填写与画布一致的数值。
4. 勾选「通过 OBS 控制音频」，特效的音效才会进入直播。
5. 取消勾选「不可见时关闭源」和「场景变为活动状态时刷新浏览器」，避免切换场景时漏播。
6. 把「星临特效」拖到来源列表最上方。

添加完成后，「直播软件输出」页会显示特效页已在线，以及它运行在什么环境中。首次使用建议先用浏览器源打开页面上的**兼容性自检页**，确认特效和声音都正常。

星临更新后，已经打开的特效页会在当前特效播完、空闲 2 秒后自动刷新成新版本，不需要手动刷新浏览器源。管理后台不会自动刷新：有新版本时页面顶部会提示，点「刷新」即可。

> 浏览器源地址中带有访问密钥，请不要公开。泄露后可以在「直播软件输出」页重置密钥，旧地址会立即失效。

需要竖屏直播、横屏录播等多种画面时，可以新建多个输出，每个输出有自己的地址和画布设置，播放内容保持同步。

**弹幕列表**

弹幕列表把直播间里所有人的弹幕排成一列显示在直播画面上（最多 8 条，新的从下面进来）。它是同一个输出的另一个地址，在「直播软件输出」页的「弹幕列表」里复制：

1. 在直播软件里再添加一个浏览器（网页）素材 / 来源，命名为「星临弹幕」。
2. 粘贴弹幕列表地址，宽高填 **600 × 900**（高一点能放满 8 条，矮了就少显示几条）。
3. 拖到画面左边或右边。想改大小请改宽高数字或后台的「字号」，不要直接拉伸，否则会变形。

在「弹幕列表设置」里可以选靠左或靠右对齐（放在右边时选靠右，头像跟着换到右边）、字号，以及粉丝牌只显示本直播间的还是戴什么显示什么。不用时关掉右上角的开关，直播画面上就不再显示。弹幕列表不受触发规则、黑名单和「暂停所有特效」影响。

## 2. 触发规则

「触发规则」页分为**进场、弹幕、礼物、上舰**四类，每条规则都写成一句话：谁、做了什么时，播放哪个特效。改动立即生效。

- 点 ▶ 在预览小窗中播放效果（使用真实的特效页，只在这里播放，观众看不到）；小窗中的「发送到直播测试」会真的播放到直播画面上。
- 点右上角的「模拟一下」，假装发生一件事（例如一位 21 级粉丝牌的观众进场），查看会使用哪条规则、播放什么，不会真的播放，也不会记录。
- 每条规则都可以单独开关；关闭后，这部分观众按下一条符合的规则处理。

### 2.1 进场

有人进场时，按以下顺序查找，使用**第一条**符合的规则：

**专属用户 → 大航海（总督、提督、舰长）→ 房管 → 粉丝牌 → 其他观众**

- **专属用户**：为指定的观众设置单独的特效，永远最先使用，可以设置有效期（例如生日当天）。在总览的实时动态中点某位观众，也可以直接设置。
- **大航海**、**房管**：只算本直播间的身份。
- **粉丝牌**：只算本直播间的牌子，按等级分段，每一段放一种特效。在等级条下方输入等级即可再分出一段。
- **其他观众**：以上都不符合的观众，默认关闭。直播间人多时建议保持关闭，以免刷屏。

**不重复播放的方式**：

- **按时间**：每条规则单独设置「同一个人多久内不重复」，可选不限、1、5、10、30 分钟、1 小时，或自定义。
- **每场直播只播一次**：同一个人在一场直播中只播放一次，下一场重新计算。

### 2.2 弹幕

观众发的弹幕里有指定的关键词时播放特效。

- 匹配方式：「里有」（包含关键词）或「就是」（与关键词完全一致）。
- 可以限定谁发的才算（可以多选，满足任意一项就算）：所有人、主播、房管、总督、提督、舰长、戴本房间粉丝牌且不低于某一级、荣耀等级不低于某一级、指定观众（填 UID）。
- 「主播本人不触发」「登录的 B 站账号不触发」开着时，主播、登录的账号发的弹幕默认不触发；规则里勾了「主播」或者填了 TA 的 UID，就照样触发。手动拉进黑名单的人，怎么设置都不触发。
- 可以分别设置**全场**多久内只播一次、**同一个人**多久内不重复，防止刷屏。
- 多条规则都符合时，使用排在最上面的一条，可以用箭头调整顺序。
- 还没有弹幕规则时，页面会提供「生日快乐」「晚安」「签到」「主播好」等常用例子，点击即可添加。

### 2.3 礼物

- **指定礼物**：从本直播间的礼物面板中选择礼物，送出这些礼物时优先使用这里的特效。礼物按编号匹配，同名不同价的礼物可以区分开。
- **按价值**：其余礼物按一次送出的总价值（单价 × 数量）分段，每一段放一种特效。刻度条展示了每一段的金额范围和对应特效；低于最低一段的礼物不播放。
- **连击合并**：同一个人在设定的几秒内连续送同一种礼物，合并为一次特效，显示总数量。
- 免费礼物不触发特效。

### 2.4 上舰

有人开通或续费大航海时播放。总督、提督、舰长各一条规则，开通和续费可以用同一个特效，也可以点「续费用别的特效」分开设置。上舰特效默认插队优先播放。

## 3. 素材库

素材库中的每一项都是一个可以在规则里选用的特效。

- **内置素材**：随星临提供，不能直接修改。点「复制并编辑」可以在副本上自由调整。

  | 素材 | 风格 | 默认用在 |
  |---|---|---|
  | 金銮 / 亭阁 / 门楼 | 东方宫廷 | 总督 / 提督 / 舰长的进场和上舰 |
  | 晶耀 | 玻璃质感，画面中间的大面板，礼物图放大 | 礼物 1000 电池（100 元）以上 |
  | 晶礼 | 玻璃质感卡片，礼物图弹出、数量滚动 | 礼物 100 ~ 1000 电池（10 ~ 100 元） |
  | 晶巡 | 玻璃质感，带「房管」标签 | 房管进场 |
  | 晶语 | 玻璃质感气泡，显示弹幕内容 | 新建弹幕规则时的默认特效 |
  | 霜玻 / 霜玻·简 | 磨砂玻璃条，带粉丝牌 | 粉丝牌进场 / 普通观众进场（默认关闭） |
  | 一行字 | 只有一行文字 | 礼物 10 ~ 100 电池（1 ~ 10 元，默认关闭） |
- **我的素材**：把文件拖进素材库即可上传，支持透明 WebM（推荐）、MP4、SVGA、Lottie（.json）、GIF、PNG、WebP，单个文件不超过 100 MB。视频没有透明背景时会提醒。
- **音效**：MP3、WAV、OGG，单独管理，可以被多个素材共用。
- 正在被规则使用的素材不能删除。

素材库里每张卡片底部有「重命名」「复制」「删除」按钮：重命名直接在卡片上改，按回车保存、Esc 取消；删除要点两次确认，正在被触发规则使用的素材不能删。音效卡片也可以重命名。

点开一个素材可以设置：画面、是否叠加头像和欢迎语、欢迎语、音效与音量、位置与时长，右侧可以实时预览（包括还没保存的修改）。视频、SVGA、Lottie、动图默认按文件本身的时长完整播放；想让它提前结束，打开「手动设置时长」填秒数（最长到素材本身的长度）。静态图片直接设置显示几秒。上传的素材还可以分别打开「开头渐入」「结尾渐出」，新上传的默认关闭；打开后可以填渐入、渐出各用几秒（0.1 ~ 5 秒）。叠加的头像和欢迎语只显示约 4.5 秒。打开「大航海头像框」后，舰长、提督、总督的头像会套上 B 站的头像框。打开「荣耀等级勋章」后，观众昵称前面会放上 B 站的荣耀等级勋章（和 B 站弹幕里的一样，每一级一张图），没有荣耀等级的观众不显示；内置样式也能用（先「复制并编辑」）。上传的素材选好位置后还可以再挪：在左边预览里按住素材拖到想要的地方，或者用「上下挪动」「左右挪动」滑块微调（按画面宽、高的百分比算，横屏竖屏都一样），「回到原位」清零；挪进顶部信息栏、底部弹幕区时会提醒。「大小」滑块可以把素材放大或缩小（20% ~ 200%，100% 是自动算出的大小：选「居中」时铺满画面，选左下、右下、顶部时会自动缩小到画面高度的 45% 以内）。点弹窗左上角的素材名称（旁边有铅笔图标）就能改名。「① 画面」里的「上下羽化」可以让视频的上下边缘慢慢变透明：默认「跟随全局」（在「设置 → 素材显示」统一打开和调宽度，只对没有透明通道的素材生效），也可以「自己设置」宽度或选「不羽化」。

**SVGA 动态图层**：SVGA 特效里可以预留图层，播放时换成进场观众的信息。上传 SVGA 后，素材设置「① 画面」里会列出所有图层，每个图层选一项：头像（圆形 / 方形）、头像框（舰长、提督、总督的 B 站头像框）、身份图标（船锚）、昵称、欢迎语，或者不替换。头像框和身份图标只给大航海观众显示，其他观众这一层会藏起来；昵称、欢迎语放不下时自动缩小字号。

找设计师做 SVGA 时，可以请对方把图层（图片的名字）按下面命名，上传后会自动对应好：

| 图层名 | 换成 | 建议 |
|---|---|---|
| `avatar` | 头像（圆形） | 正方形占位图，例如 200×200 |
| `frame` | 头像框 | 正方形，约为头像的 1.4 倍，和头像同一个中心 |
| `badge` | 身份图标（船锚） | 正方形，例如 64×64 |
| `honor` | 荣耀等级勋章 | 扁长方形，按 36×16 的比例，例如 108×48；勋章按原比例放在中间，没有荣耀等级的观众这一层会藏起来 |
| `nickname` | 昵称 | 按想要的文字区域大小做一张占位图，文字画在里面、居中 |
| `welcome` | 欢迎语 | 同上 |

买来的 SVGA 图层名常见的写法（head、头像、nick、name、kuang 等）也会自动识别，识别不了的可以自己选。

### 欢迎语变量

每行一句，播放时随机选一句；不同事件可以写不同的欢迎语，没写的使用「通用」。

| 变量 | 含义 | 适用事件 |
|---|---|---|
| `{name}` | 昵称 | 全部 |
| `{guard}` | 大航海身份（总督 / 提督 / 舰长） | 全部 |
| `{medal}`、`{level}` | 粉丝牌名称、等级 | 全部 |
| `{honor}` | 荣耀等级（数字，没有时为空） | 全部 |
| `{text}` | 弹幕内容 | 弹幕 |
| `{gift}`、`{count}`、`{value}` | 礼物名称、数量、总价值 | 礼物 |
| `{months}` | 月数 | 上舰 |
| `{op}` | 开通 / 续费 | 上舰 |
| `{act}` | 上舰 / 续费 | 上舰 |

## 4. 直播中

### 4.1 总览

- **直播间**：正在监控的直播间、主播、标题、分区，以及 B 站记录的开播时间和已播时长。
- **数据**：开播时默认显示本场，没开播时默认显示今天，可以手动切换。一排 6 个数字：进场人数（去重）、触发特效次数，以及 B 站的看过人数、高能榜人数、点赞数、粉丝数。
- **实时动态**：最新的进场、弹幕、礼物、上舰、醒目留言，以及是否播放了特效（醒目留言现在只记录，不触发特效）。可以只看某一种（进场 / 弹幕 / 礼物和醒目留言 / 上舰），或者打开「只看大航海」（从最近 150 条里挑，更早的去「事件记录」查）。鼠标停在列表上时暂停滚动，方便点人，移开后再显示新来的。点任意一行可以为这位观众设置专属特效、复制 UID 或加入黑名单。
- **右侧面板**有 4 个标签，选过的会记住：
  - **播放队列**：正在播放的一条（带进度）和排队中的特效（大约多久后播放）。可以跳过当前、把某一条移出队列，或清空排队；「排队设置」中可以调整高价值插队和最多排队条数。标签上显示条数（绿色表示正在播放），没有时显示「空闲」；有特效播放时不会自动切换过来。
  - **在线观众**：在线人数和在线名单（和 B 站直播间里的「在线观众」一样），按贡献排序（单位是电池），还没有贡献的观众也在，每 30 秒刷新。B 站最多只给前 100 位；隐身、没登录 B 站的观众不在名单里。可以只看大航海或戴本房间粉丝牌的。
  - **礼物榜**：这段时间（本场 / 今天，跟着上面的数据范围）每人花了多少（电池，小字是金额）：付费礼物、上舰（按实际支付的价格，有折扣的按折扣价）、醒目留言都算。盲盒按开出来的礼物算，和 B 站高能榜一样。每行写着送了几次、最贵的一件，有上舰、醒目留言的会标出来。和 B 站高能榜上的电池数比，可能差几个电池：B 站还给点赞、发弹幕加少量的分。
  - **大航海**：这段时间来了哪些舰长、提督、总督，各进场几次、最后一次什么时候；加上 B 站的舰队名单，显示「舰队 N 人，来了几人」，点开「还没来的」能看到没来的人（舰队名单 15 分钟更新一次，人特别多时只读前 1200 人）。
  - 名单里点任意一行，和实时动态一样，可以设置专属特效、复制 UID 或加入黑名单。
- **身份构成**：进场观众的身份比例，下面是荣耀等级分布（每人按最后一次进场时的等级）。

数据按直播间分别统计，切换直播间后显示新直播间的数据。

### 4.2 暂停与播放顺序

- **紧急暂停**：点顶部的「暂停所有特效」，或按 `Ctrl + Shift + P`。直播画面上的特效立即停止，排队中的特效被清空，事件照常记录。快捷键只负责暂停（慌忙中多按一次也不会变成恢复）；恢复请点「恢复播放」。
- **播放顺序**：上舰 → 礼物 → 进场 → 弹幕。上舰和 1000 电池（100 元）以上的礼物可以插队（可在「排队设置」中关闭）。排满后，先挤掉顺序最靠后、最早进来的一条。

### 4.3 事件记录

每个事件都会记录：发生时间、观众、命中了哪条规则、播放的特效，以及没有播放的原因，例如：

| 状态 | 含义 |
|---|---|
| 已播放 / 排队中 | 正常 |
| 未命中规则 | 没有符合的规则，或规则已关闭 |
| 冷却中 | 在「多久内不重复」的时间内 |
| 本场已播过 | 开启了「每场直播只播一次」 |
| 黑名单 | 这位观众在黑名单中 |
| 未开播 | 没有开播，且未开启排练模式 |
| 已暂停 / 已清空 | 暂停或清空队列时还没播放 |
| 特效页不在线 | 当时没有特效页连接 |
| 队列已满，丢弃 | 排队条数达到上限 |

可以按事件类型、状态筛选，或按昵称、UID 搜索。

## 5. 设置

| 分组 | 内容 |
|---|---|
| **B站账号** | 扫码登录、登录状态与剩余有效期、退出登录 |
| **直播间** | 房间号（短号、长号都可以） |
| **播放** | 未开播时（不播放 / 照常播放，用于排练）；连接直播间（只在开播时 / 一直连接） |
| **黑名单** | 这些观众不会触发任何特效，事件照常记录；主播本人、登录的 B 站账号是否触发 |
| **管理后台** | 修改登录密码 |
| **数据** | 每天自动备份（保留 7 份）、立即备份（另外保留 5 份）、事件记录保留天数、导出 / 导入配置 |

页面右上角可以重新打开新手引导。

**导出 / 导入配置**：导出的配置可以包含素材文件，用于备份或迁移到另一台服务器。导入前会先显示有哪些变化，确认后才生效。

## 6. 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl + K` | 打开命令面板：搜索页面、预览某个身份的进场特效、暂停 / 恢复、清空队列等 |
| `Ctrl + Shift + P` | 暂停所有特效（恢复请点按钮） |
| `Esc` | 关闭弹窗、预览小窗 |

## 7. 在手机上使用

管理后台适配手机，用手机浏览器打开同一个地址即可，底部有导航栏。直播中可以随时暂停特效、查看实时动态、设置专属用户。
